# Штаб для iPhone

Штаб и сетевой пульт Bridge в одном приложении для iOS 17+. Живые разделы загружаются с https://shtab.bagavievalexe.workers.dev; вход по своему ключу сохраняется в контейнере WebKit. Ключей и пользовательских данных в репозитории нет.

Внешние панели и вкладки убраны. Bridge находится только в карточке ноутбука; отдельная кнопка в нижнем меню убрана. Масштабирование страницы и автоматический зум полей отключены. Тема переключается кнопкой самого Штаба: системная, светлая, тёмная; оформление iOS следует выбору. Иконка всегда светлая. Для обновления потяни страницу вниз; при открытой форме или панели управления жест не перезагружает страницу.

Сетевой кликер и тачпад используют существующий сервер Штаба и Bridge Windows. В версии 0.3 добавлен первый Bluetooth-транспорт: выбор ноутбука в карточке, HMAC-проверка существующего ключа Штаба, защищённое хранилище iPhone, подтверждённые короткоживущие команды и возврат на интернет при обрыве. Требуется обновлённый Windows Bridge. Аппаратное сопряжение и управление нужно проверить на физическом iPhone; симулятор BLE не подтверждает. Прямой локальный Wi-Fi и нативные push-уведомления iOS ещё не реализованы.

## Сборка и установка

GitHub Actions → iOS Build (Unsigned IPA) → Run workflow. Workflow генерирует Xcode-проект через XcodeGen на macos-15, собирает приложение, запускает XCTest и сохраняет неподписанный IPA в Artifacts. Подпись и установка выполняются на Windows через Sideloadly; Apple ID в GitHub не передаётся. Bundle ID остаётся ru.atmosproduction.bridgephone для обновления существующей установки.

Основа проекта — hoangnd107/ios-swiftui-app-template (MIT); исходная лицензия сохранена.
