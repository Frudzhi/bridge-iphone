# Bridge iPhone — первая проверочная сборка

Нативный SwiftUI-проект для iPhone, iOS 17+. Основан на `hoangnd107/ios-swiftui-app-template` (MIT; лицензия сохранена).

Этот этап проверяет сборку на облачном Mac и установку через Sideloadly с Windows. BLE, сетевые адаптеры и управление Windows ещё не подключены. Текущий Bridge Windows не заменяется.

Подготовлены имя Bridge, схема BridgePhone, bundle ID `ru.atmosproduction.bridgephone`, начальный экран и политика Bluetooth → Wi-Fi → интернет с возвратом к Bluetooth. XCTest-сценарии покрывают приоритет, возврат и отсутствие связи.

Workflow `iOS Build (Unsigned IPA)` запускается вручную на `macos-15`: XcodeGen → unsigned .app → IPA в Artifacts. Apple ID и сертификаты в GitHub не передаются. Автоматические Releases отключены. Персональных адресов, токенов и учётных данных в проекте нет.
