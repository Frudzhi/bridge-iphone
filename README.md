# Штаб для iPhone

Штаб и сетевой пульт Bridge в одном приложении для iOS 17+. Живые разделы загружаются с https://shtab.bagavievalexe.workers.dev; вход по своему ключу сохраняется в контейнере WebKit. Ключей и пользовательских данных в репозитории нет.

Внешние панели и вкладки убраны. Bridge находится внутри навигации Штаба. Тема переключается кнопкой самого Штаба: системная, светлая, тёмная; оформление iOS следует выбору. Иконка всегда светлая. Для обновления потяни страницу вниз; при открытой форме или панели управления жест не перезагружает страницу.

Сетевой кликер и тачпад используют существующий сервер Штаба и Bridge Windows. Прямой Bluetooth, автоматическое переключение Bluetooth/Wi-Fi/интернет и нативные push-уведомления iOS пока не реализованы.

## Сборка и установка

GitHub Actions → iOS Build (Unsigned IPA) → Run workflow. Workflow генерирует Xcode-проект через XcodeGen на macos-15, собирает приложение, запускает XCTest и сохраняет неподписанный IPA в Artifacts. Подпись и установка выполняются на Windows через Sideloadly; Apple ID в GitHub не передаётся. Bundle ID остаётся ru.atmosproduction.bridgephone для обновления существующей установки.
